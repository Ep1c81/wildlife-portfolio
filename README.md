# Wildlife Conservation & Rehabilitation Portfolio

A clean, responsive single-page resume portfolio designed specifically for wildlife biologists, conservationists, and rehabilitation specialists.

## Features
- **Responsive Layout**: Powered by Tailwind CSS CDN.
- **Wildlife Focused**: Tailored sections for field research, rehabilitation records, and educational outreach.
- **Lightweight**: Single file structure (`index.html`) with no build process required.

## Quick Deployment

### Step 1: Push to GitHub
1. Create a new repository on [GitHub](https://github.com).
2. Add `index.html` and `README.md` to your repository.
3. Commit and push your changes.

### Step 2: Deploy on Vercel
1. Log in to [Vercel](https://vercel.com).
2. Click **"Add New"** > **"Project"**.
3. Import your GitHub repository.
4. Keep all default settings (Framework Preset: **Other**) and click **Deploy**.

Your portfolio will be live in seconds!
